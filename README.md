# 🧠 Final Year Project (FYP)

This project includes setup and execution scripts for **Windows** users.

## 📁 Files

- `setup.bat` – Installs dependencies and sets up the environment.
- `run.bat` – Launches the frontend and backend in separate terminal windows.

## 🚀 Getting Started

1. Run `setup.bat` to install all required packages.
2. After setup is complete, run `run.bat` to start the full application.
